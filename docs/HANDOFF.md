### ท่ากด: สิ่งที่เรียนรู้

- ต้นแขน 24.6 ซม. ปลายแขน 25.9 ซม. ถ้าปลายแขนตั้งตรง ระยะมือจากไหล่ถูกกำหนดแล้ว
  จึงได้ไม่ครบทั้งเส้นทางตรงเป๊ะ ปลายแขนตั้งตรง และจุดปลายสองจุด เจ้าของอนุญาตให้ผ่อนเส้นทางตรงได้
- เส้นทางมองจากหน้า: ขึ้นเกือบตรงจากจุดล่างที่กว้าง แล้วค่อยเข้าด้านในช่วงท้าย (`SQUEEZE_LATE`)
- `pushOut` ของ shoulder press (0.05) โป่งออกเล็กน้อยช่วงเริ่มดัน ส่วน incline ตั้ง 0

### Hammer curl: ค่าที่วัดได้

จุดที่หยุดการงอศอกคือดัมเบลชนตัว ไม่ใช่ข้อศอกหรือผิว

| ศอกงอ | ดัมเบลห่างจากลำตัว หัว ขา | ผิวข้อพับ |
|---|---|---|
| 8° (แขนลงสุด) | 4.6 ซม. | ปกติ |
| 90° | 20.3 ซม. | ปกติ |
| 130° (ยกสุด) | 8.0 ซม. | รอยพับด้านในเรียบ |
| 140° | 1.9 ซม. | เริ่มยุบ |
| 145° | 0.1 ซม. | ดัมเบลแทบชน |
| 150° | ชน | ปลายศอกด้านหลังแบนเป็นขอบ |

สิ่งที่ตัดสินใจเองและรอเจ้าของยืนยัน: ดัมเบลหมุนตามปลายแขนแทนการรักษาระนาบ, ปลายแขนกางออก 8°
ตอนเหยียด, ต้นแขนกาง 9°, ศอกขยับหน้าได้ไม่เกิน 12°, เท้ากว้าง 0.15 ม. จากกึ่งกลาง และข้อความจัดท่าใน `press.ts`

## เรื่องที่ค้างอยู่

1. เจ้าของยังไม่ได้บอกว่า hammer curl ผ่านหรือไม่ แม้จะสั่ง merge เพื่อย้ายงานแล้ว ให้ถือว่ายังแก้ได้
2. เจ้าของยังไม่ได้ตอบว่า incline ควรมี `pushOut` แบบ shoulder press ด้วยไหม อย่าเปลี่ยนเองก่อนถาม
3. แผนที่สีกล้ามยังมีขอบหยักเล็กน้อยที่ข้างคอใต้ขากรรไกรและด้านนอกเข่า (น่าจะเป็นตะเข็บ UV ยังไม่ได้ยืนยัน)
4. บน localhost ชื่อท่าด้านบนขึ้น "…" เพราะไม่ได้ตั้ง `NEXT_PUBLIC_API_URL` ถ้าตั้ง ต้องดู `ALLOWED_ORIGINS`
   ของ API ด้วย ค่าใน `.env.example` อนุญาตพอร์ต 3000 ส่วน dev server ใน `.claude/launch.json` ใช้ 3100

### Push-up: สิ่งที่ตกลงกับเจ้าของ

- ทั้งตัวเป็นแผ่นแข็งเส้นเดียว หมุนรอบโคนนิ้วเท้า มือวางนิ่ง ไหล่จึงเลื่อนไปทางหัว 8.5 ซม. ระหว่างทางลง
  มือจึงตรงกับไหล่ได้แค่ตอนบนสุดหรือตอนลงสุด อย่างใดอย่างหนึ่ง
- เจ้าของเลือก: ตอนขึ้นสุดมองจากด้านข้างแขนตั้งตรงใต้ไหล่ ตอนลงสุดมืออยู่แถวราวนม อกห่างพื้น 4 ซม.
  มองจากด้านหน้าปลายแขนตั้งตรง (ศอกไม่กาง) แลกกับปลายแขนเอนไปทางเท้า 21°
- ข้อมือกระดก 90–96° และศอกย้อนกลับเล็กน้อยช่วงท้าย เจ้าของรับว่าเป็นธรรมชาติ
- หมุดตัวเลขจางเมื่อทับตัวโมเดลบนจอ (`pin-cover.ts`) ไม่ได้ดูจากทิศที่จุดหันอีกแล้ว

### Overhead triceps extension: สิ่งที่ตกลงกับเจ้าของ

- แขนเดียวเล่นแขนขวา มือซ้ายเท้าเอว ต้นแขนเกือบตั้งตรง ลดดัมเบลเฉียงไปหลังซ้าย ลงสุดศอก 125° (ดัมเบลห่างต้นคอ 2.7 ซม.)
- สองมือ อุ้งมือประสานโอบแผ่นบน ด้ามอยู่ระหว่างนิ้วโป้งกับนิ้วชี้ ศอกเฉียงหน้า 18° ขึ้นสุดศอกงอค้าง 35° ดัมเบลเอียง 40°
  (ถ้าตั้งตรงเหนือหัว แผ่นล่างชนหัว หรือไหล่บิดเกินเกณฑ์) ลงสุดศอก 130° นิ้วงอจนแตะดัมเบล
- ต้นแขนบิดมาก (แขนเดียว 137° จากท่าพัก) ผิวหัวไหล่เคยบีบเหลือแผ่นบาง จึงเพิ่มกระดูกช่วยบิดตอนโหลด (`arm-twist.ts`)
  เปิดเฉพาะท่านี้ (`enableArmTwist`) ถ้าเปิดกับ shoulder press ผิวรักแร้ซ้อนเกินเกณฑ์ test (4.9 ซม.)
- ปุ่มเลือกรูปแบบ (`way-switch.tsx`) อยู่เหนือภาพ 3D ทั้งท่านี้และ hammer curl
- บ่า: ไหปลาร้ายก 28° และหมุนไปทางหลัง 30° ตอนแขนอยู่เหนือหัว บ่านูน (`aTraps`) เจ้าของเลือกแบบ ก+ข
- ศอกกางออก: แขนเดียว 12° (เอนหน้า 10° ด้วย ไม่งั้นไหล่บิดเกิน), สองมือ 6° ตอนลง ศอกเลื่อน 2.6 ซม.

### ผิวหัวไหล่ตอนชูแขน (ทุกท่า)

- `delta-mush.ts`: เกลี่ยผิวรอบหัวไหล่ทุกเฟรมแบบ Corrective Smooth ของ Blender แล้ววางรายละเอียดผิวเดิมกลับ
  (เครื่อง Mac ไม่มี Blender จึงคำนวณสดในเว็บ) ค่อย ๆ ลดลงใต้รักแร้
- ลองแล้วไม่ดี: เกลี่ยน้ำหนักผิว (เนื้อดูถูกเฉือน), ดันเนื้อออกตรง ๆ (ปูด), กระดูกสะบัก (หลังแข็งเป็นก้อน), ผิวโปร่ง (เห็นข้างในหัว)
- ผิวแขนซ้อนเข้าบนหัวไหล่ได้ถึง 5.1 ซม. (มองไม่เห็น) เจ้าของรับเกณฑ์ 5.5 ใน shoulder press และ overhead
- dev server รับมือถือในวง Wi-Fi เดียวกัน (`allowedDevOrigins`) แต่ GlobalProtect บน Mac อาจกันอยู่ ใช้ Vercel preview แทน

## เครื่องมือ

- ดูท่า: ตั้ง dev server จาก `.claude/launch.json` (ชื่อ `web`, พอร์ต 3100)
- ถ่ายภาพตรวจ: `tools/body/shots.mjs` วิธีใช้อยู่หัวไฟล์
- Test: `npm test` ใน `apps/web` และ lint ด้วย `npm run lint`
- สร้างตัวโมเดลใหม่ (ต้องมี Blender 4.5):
  `blender --background --python tools/body/build.py -- apps/web/public/models/body.glb [render_dir]`
  ใส่ `render_dir` เพื่อได้ภาพแผนที่กล้ามทั้งตัว 1 สีต่อ 1 กล้าม ไว้ตรวจขอบสี
  ขอบสีบนลำตัว ศอก และเข่า กำหนดจากตำแหน่งบนตัว (ฟังก์ชัน `abs_edge`, `traps_edge`, `delto_pec` ฯลฯ)
  และใช้ร่วมกับร่องกล้ามใน `relief.png` แก้ที่เดียวทั้งสีและร่องตามกัน
- ค่ากล้ามเนื้อปัจจุบัน: `MACRO` muscle 0.9, pectoral 0.4, dorsi 0.5, upperarm 0.7, shoulder 1.0, lowerleg 0.2
- `tools/body/out/` ไม่อยู่ใน git เพราะมีไฟล์ Mixamo ดิบ repo เป็น public ห้ามเผยแพร่ไฟล์เหล่านี้
  ไฟล์ชุดนี้ยังอยู่บน Mac ถ้าจะ bake ท่า Mixamo ใหม่ต้องหาไฟล์ต้นทางมาใหม่
